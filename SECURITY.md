# Политика безопасности | Security Policy

## Поддерживаемые версии | Supported Versions

В настоящее время мы поддерживаем актуальную основную ветку репозитория с исправлениями безопасности. Если вы используете более старую версию шаблона, рекомендуется обновиться до последней.

We currently support the main branch of the repository with security fixes. If you are using an older version of the template, please update to the latest one.

| Версия | Version         | Поддерживается | Supported |
|--------|-----------------|----------------|-----------|
| main   | (latest commit) | ✅             | ✅        |
| < main | (previous)      | ❌             | ❌        |

## Сообщение об уязвимости | Reporting a Vulnerability

Мы серьезно относимся к безопасности. Если вы обнаружили потенциальную уязвимость в коде шаблона или его зависимостях, пожалуйста, не создавайте публичный Issue.

We take security seriously. If you discover a potential security vulnerability within this project, please **do not** open a public issue.

Вместо этого, свяжитесь с сопровождающим напрямую одним из способов:

Instead, please report it to the maintainer directly:

1.  **Открыть issue с пометкой "SECURITY"** (только для чувствительных, но не критических проблем). В описании укажите, что речь идет об уязвимости.
    **Open a draft security advisory** on GitHub (if the repository allows it) or create a regular issue with the "SECURITY" label (for sensitive but non-critical issues).
2.  **Написать на email** (связаться с @yamadharma через email, указанный в его профиле GitHub).
    **Send an email** to the maintainer (contact @yamadharma via the email listed on his GitHub profile).

Мы постараемся ответить как можно скорее и будем держать вас в курсе процесса исправления.

We aim to respond promptly and will keep you informed about the progress.

Спасибо, что помогаете делать проект безопаснее! | Thank you for helping keep the project secure!
