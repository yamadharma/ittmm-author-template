# Руководство по внесению вклада | Contributing Guide

Спасибо за интерес к улучшению шаблона для конференции ITTMM! Этот проект существует благодаря сообществу, и мы рады любой помощи.

Thank you for your interest in improving the ITTMM conference template! This project thrives through community involvement, and we welcome all forms of contribution.

## Как вы можете помочь | How You Can Contribute

*   **Сообщение об ошибках | Reporting Bugs**
    Если вы нашли ошибку в шаблоне (например, неправильное форматирование, опечатку, проблему с компиляцией), пожалуйста, создайте **Issue** на GitHub. Опишите проблему как можно подробнее: укажите шаги для воспроизведения, ваше окружение (ОС, версия LaTeX) и приложите минимальный пример кода, демонстрирующий ошибку.
*   **Предложения по улучшению | Suggesting Enhancements**
    Если у вас есть идея, как сделать шаблон лучше (например, добавить новую опцию, улучшить документацию), также создайте **Issue** с меткой `enhancement`.
*   **Исправление ошибок и улучшение документации | Pull Requests**
    Мы приветствуем Pull Request (PR) с исправлениями и улучшениями.
    1.  **Форкните** репозиторий.
    2.  Создайте **ветку** для ваших изменений (`git checkout -b feature/amazing-idea`).
    3.  Внесите изменения. Пожалуйста, убедитесь, что шаблон по-прежнему компилируется без ошибок.
    4.  Обновите документацию в файлах `.md`, если это необходимо.
    5.  Сделайте коммит с **понятным и информативным сообщением** на английском или русском языке.
    6.  Откройте **Pull Request** в основной репозиторий. Подробно опишите ваши изменения.

## Правила оформления кода | Code Style Guide

*   **Языки | Languages**
    *   Основные файлы шаблона (`*.tex`) должны корректно работать как для русской (`ittmm-author-template-ru`), так и для английской (`ittmm-author-template-en`) версий.
    *   При добавлении новых опций или команд LaTeX, пожалуйста, комментируйте их код на английском языке для доступности международному сообществу.
*   **LaTeX**
    *   Старайтесь следовать существующему стилю оформления кода (отступы, комментарии).
    *   Изменения не должны ломать обратную совместимость без веской причины.
*   **Документация**
    *   Файлы документации (`README.md` и др.) поддерживаются на **русском и английском языках**. Если вы добавляете новый раздел в `README`, пожалуйста, добавьте его для обоих языков.

## Процесс ревью | Review Process

После открытия Pull Request, сопровождающие проекта (`yamadharma`) или другие участники сообщества могут оставить комментарии или запросить изменения. Мы стараемся обрабатывать PR в разумные сроки. Пожалуйста, будьте готовы к обратной связи и доработкам.

Еще раз спасибо за ваш вклад! | Thank you for contributing!
